# Smart-Battery-Monitor

The Smart Battery Monitor was created to PROTECT your battery when it's at 100%. This is currently available for Windows only (Windows 10 + 11). Linux support will be soon. Sounds and Notifications will spam until you unplug your charger. Hopefully this is useful to others.
